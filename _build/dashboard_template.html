Gaps & next steps

  • No public paired smart-vs-standard metered urban zones anywhere (closest: NC State homes, Orange County homes, Melbourne turf arms).
  • No open Saudi/GCC irrigation, soil-moisture or plant-condition data. KSU (S1, S2) and Shaqra (S11) offer data on request; others publish none.
  • No public recommendation / override logs (R5): SIMPaCT and Frankfurt describe them but do not release them.
  • Regional effect-size priors: landscape controllers saved ~6–15% (Tehran park, IR1), ~21–26% (Dubai, U1), 18–25% (KSU ET controllers, S4); historic Riyadh over-irrigation 23–33 vs 15 L/m²/day (S3). Use for the 12-pair power calculation.
  • Next: (1) request KSU PCMT site data (Alazba/Elkatoury) as the ET comparator; (2) request KFU date-palm sensor logs (memohammed@kfu.edu.sa); (3) prototype sensor_log + ET0 pipeline with the open Souss-Massa dataset and NCM Riyadh weather; (4) build a hybrid test set (Apulia metered schema, Melbourne treatments, DigiWaVe trees); (5) obtain NCM API credentials for Riyadh station.
